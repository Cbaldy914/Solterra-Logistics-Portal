# Solterra Logistics Portal

Solterra Logistics Portal is a PHP-based web application for managing deliveries, projects, warehouses and related logistics tasks. The repository contains the application code while sensitive configuration is kept outside the repo.

## Requirements

This project uses Composer dependencies that require **PHP 7.1 or later**. The version check generated by Composer can be seen in `vendor/composer/platform_check.php`:

```
if (!(PHP_VERSION_ID >= 70100)) {
    $issues[] = 'Your Composer dependencies require a PHP version ">= 7.1.0".';
}
```

## Installing Dependencies

After cloning the repository, install PHP and [Composer](https://getcomposer.org/). Then run:

```
composer install
```

This installs the required packages such as `dompdf/dompdf` defined in `composer.json`.

## Configuration

An external `config.php` file is required for database connectivity and other sensitive settings. Place this file **one directory above** the project root so that application files can load it with `require_once '../config.php';`.

The file should return or define values using environment variables, for example:

```php
<?php
$host = getenv('DB_HOST');
$user = getenv('DB_USER');
$pass = getenv('DB_PASS');
$name = getenv('DB_NAME');

function getDBConnection() {
    global $host, $user, $pass, $name;
    return new mysqli($host, $user, $pass, $name);
}
```

Set `DB_HOST`, `DB_USER`, `DB_PASS` and `DB_NAME` in your environment to match your database server.
