### Glossary of Key Terms

| Term | Definition |
|------|-----------|
| **Module** | A single solar panel unit. Modules are grouped into batches from a manufacturer. |
| **Module Batch** | A group of modules from one manufacturer with the same specs — like a purchase order for panels. |
| **Wattage** | The power output rating of a module (e.g., 400W, 500W). Higher wattage = more powerful panel. |
| **Pallet** | A standardized shipping unit that holds multiple modules. Modules must be palletized before shipping. |
| **Palletization** | Organizing modules onto pallets for transport. You define how many modules fit per pallet based on dimensions. |
| **Megawatt (MW)** | 1,000,000 watts. Used to describe project size. 1 MW is roughly 2,000–2,500 modules depending on wattage. |
| **Cost per Watt ($/W)** | Total module cost divided by total wattage. The standard industry metric for comparing solar module pricing. |
| **Domestic Content %** | Percentage of a module's value from US-manufactured components. Higher % may qualify for IRA tax credits. |
| **BOL (Bill of Lading)** | The shipping document that serves as a receipt and contract between shipper and carrier. Every shipment gets a unique BOL. |
| **Master BOL** | For overseas/container shipments: tracks the entire container across the ocean voyage. |
| **House BOL** | For overseas/container shipments: tracks your specific portion within a shared container. |
| **POD (Proof of Delivery)** | Documentation confirming a shipment was received at its destination — usually a signed receipt or photo. |
| **Drayage** | Short-distance trucking, typically from a port to a nearby warehouse after customs clearance. |
| **Freight Cost** | The transportation cost charged by the carrier. |
| **Customer Cost** | The cost passed through to the customer. May differ from freight cost. |
| **Accessorial Cost** | Additional charges beyond base freight: driver detention, lumper fees, fuel surcharges, lift-gate, etc. |
| **Warehouse** | A facility that stores palletized modules between manufacturing and delivery to the project site. |
| **Port** | A facility that receives overseas container shipments and handles customs clearance before inland transport. |
| **Entry Fee** | Per-pallet charge when goods first arrive at a warehouse/port. |
| **Exit Fee** | Per-pallet charge when goods leave a warehouse/port. |
| **Monthly Storage Fee** | Recurring per-pallet charge for each month modules remain in storage. |
| **Milestone** | A payment trigger event tied to a project lifecycle stage. Example: "Pay 30% when shipping is initiated." |
| **Projection** | A delivery cost estimate modeling the route, stops, and timeline for getting modules to a project site. |
| **Stop** | A location in a delivery projection where modules pause (e.g., a port or warehouse). |
| **Leg** | A transportation segment between two stops. Each leg has its own freight cost. |
| **Flash Test Data** | Factory quality-control test results verifying each module meets its rated power output. |
| **On Water** | Modules are in transit via ocean shipping. |
| **In Transit to Warehouse** | Modules are being trucked from manufacturer or port to a warehouse. |
| **In Transit to Project** | Modules are being trucked from warehouse to the final project site. |
| **Delivered to Project** | Modules have arrived at the project site and been confirmed received. |
| **Cleared Customs** | Port only: modules passed customs inspection and are ready for inland transport. |
| **In Warehouse / In Storage** | Modules are sitting in a warehouse facility awaiting their next move. |
| **Project Health** | Assessment of whether a project is on track. Green = On Track, Yellow = At Risk, Red = Behind, Teal = Completed. |
| **Unassigned Modules** | Modules added to the system but not yet allocated to any project — available inventory. |
| **Module Movements** | Tracking feature showing where modules have been and where they are now — their location history. |

### General Portal Questions

**What is this portal?**
The Solterra Logistics Portal is the central hub for managing solar module warehousing, shipping, and delivery. Customer Admins can track module batches from manufacturer to project site, manage warehouse inventory, create shipments, schedule deliveries, upload documents, and monitor costs and milestones.

**What should a user do first after logging in?**
Review the Dashboard for a portfolio overview, click into a project to see its status, check the Modules page for batch and palletization status, create shipments if modules are palletized, receive them at a warehouse after arrival, then schedule deliveries to the project site.

**What is the general workflow?**
Plan (create project, set delivery projections) → Palletize (organize modules onto pallets) → Ship (create shipments) → Receive (confirm arrival at warehouse/port) → Schedule (set delivery appointments) → Deliver (confirm delivery, upload POD).

**How do I navigate the portal?**
The top menu groups pages by function: Projects, Modules, Warehousing, Manufacturers, Shipments, and Documents. The Profile menu (top right) has Notifications, Settings, Questions & Support, and Invoices.

**What do dashboard health badges mean?**
Green (On Track) = on schedule. Yellow (At Risk) = some delays detected. Red (Behind) = missed key dates, needs attention. Teal (Completed) = all deliveries done.

**Can users customize the dashboard?**
Yes — toggle between Grid and Table view, switch units between Modules and MW, and filter projects by clicking health badges in the chart legend.

### Projects

**How to create a project:** Go to Projects > Add Project, fill in name, address, target MW, upload site documents. After creating, the Project Overview opens.

**Project Size (MW):** Target power capacity in megawatts. 5 MW ≈ 10,000–12,500 modules.

**Order Progress:** Percentage of needed modules registered in the system from manufacturers. Does NOT mean delivered.

**Delivery Progress:** Percentage of modules actually arrived and confirmed at the project site.

**General Projection vs. project delivery plan:** A project delivery plan is tied to a specific project with actual routes/costs. A General Projection is unattached — for "what if" planning.

**Plan Set / In Progress / Add Plan badges:** Add Plan = no delivery schedule yet. In Progress = projection started but incomplete. Plan Set = complete delivery schedule with dates and routes.

**Project reports:** From Project Overview, use the Reports dropdown — Cost Analysis, Sustainability, Manufacturers, Exceptions, Export Data.

### Modules & Palletization

**Module Batch:** A group of modules from one manufacturer with same specs tracked together.

**Unassigned modules:** Batches added but not allocated to any project — available inventory.

**Palletization:** Required before shipping. Organizes modules onto pallets. Go to Module Overview, set modules per pallet, click Generate Pallets.

**How to palletize:** Modules > Manage Modules > click batch > Module Overview > enter modules per pallet > Generate Pallets. Can undo if needed.

**Domestic Content %:** Measures US-manufactured component value. Higher % may qualify for IRA tax credits (up to 10% bonus).

**Palletization badges:** Red (Not Palletized) = can't ship yet. Orange (Partially Palletized) = some done. Green (Fully Palletized) = ready to ship.

**Module Movements:** Tracking feature showing location history: At Manufacturer → In Transit → In Warehouse → In Transit to Project → Delivered.

### Shipments

**How to create a shipment:** Shipments > Create Shipment. Select palletized pallets, choose destination, enter carrier/dates/costs, click Create. Gets a unique BOL number.

**Single vs Multi mode:** Single = one shipment, one BOL, one truck. Multi = splits pallets across multiple trucks, each with its own BOL.

**BOL (Bill of Lading):** Official shipping document — receipt and contract between shipper and carrier. Referenced when receiving and scheduling.

**Master vs House BOL:** Overseas only. Master BOL = entire ocean container (shipping line). House BOL = your portion within a shared container.

**Freight vs Customer vs Accessorial Cost:** Freight = carrier's base charge. Customer = amount passed to customer (may differ). Accessorial = extras (detention, lumper fees, fuel surcharges, lift-gate).

**Overseas vs domestic:** Overseas/container flow for international ocean freight — adds Port of Entry, Container Number, Master/House BOL. Domestic trucking for in-country shipments.

**After creating a shipment:** Upload the BOL document, receive at warehouse when it arrives (or schedule delivery if going to project site), notify relevant parties.

### Warehousing & Receiving

**Why use warehousing?** Temporary storage between manufacturing and delivery — when site isn't ready, consolidating shipments, or handling overseas customs.

**Port vs Warehouse:** Port handles overseas containers + customs clearance + drayage. Warehouse is standard domestic storage. Both store pallets.

**How to receive:** Go to warehouse inventory page > find shipment in Inbound Transit > click Receive > verify quantities > report damage > upload POD. Status changes from "In Transit" to "In Warehouse."

**Storage costs:** Entry fee (per pallet on arrival) + Exit fee (per pallet on departure) + Monthly storage fee (per pallet per month). View via "Cost Structure" on the warehouse page.

**Cleared Customs:** Port-specific — shipment passed customs inspection, duties processed, ready for inland transport.

**Drayage:** Short-distance trucking from port to nearby inland warehouse after customs clearance.

**What's in storage:** Warehousing > Warehousing Overview for aggregate view, or click into a specific warehouse for detail.

### Scheduling & Deliveries

**How to schedule:** Go to the Scheduling page, select the shipment, pick date/time, add notes, save. Check site operating hours first.

**Operating hours:** Define when the project site accepts deliveries (e.g., Mon–Fri 8–5). Set during project creation.

**Reporting damage:** Edit delivery appointment > set "Has Damages: Yes" > record expected vs actual vs damaged quantities > upload photos. Creates an exception report.

**Safety incidents:** Edit delivery > "Has Safety Incident: Yes" > add notes > check "Report Driver" if applicable.

**Proof of Delivery (POD):** Documentation confirming receipt — signed delivery receipt, driver signature photo, or stamped BOL. Upload when editing the delivery.

**Marking as Delivered:** Updates all pallet statuses to "Delivered to Project." May trigger payment milestones. This is permanent — can't be undone without admin help.

**Delivery statuses:** On Water (ocean vessel) → In Transit to Warehouse → In Transit to Project → Delivered to Project. Also: At Warehouse/In Storage, Cleared Customs (port only).

**Rescheduling:** Find appointment on calendar > edit > change date/time. Coordinate with carrier and site team.

### Documents

**Document types:** 8 categories — Site (SOP, maps, safety, permits), Invoices (Solterra, freight, module), Shipments (arrival notice, customs, POD), Warehousing (POD, inventory, photos, quote), Modules (invoice, flash test, specs), Photos (project, warehouse, damage), Exception Reports (damage, warranty, safety, POD), Other.

**Project vs Global Documents:** Project Documents shows files per project. Global Documents shows everything across all projects with filters (type, sub-type, project, date).

**How to upload:** Global Documents > Upload > select project, type, sub-type, optionally link to BOL > drag-and-drop or browse.

**Finding documents:** Use Global Documents filters (project, type, date range). Can also filter by BOL number.

**What to always upload per shipment:** BOL, POD, damage photos (if any), flash test data (if available). Optional: freight invoices, customs docs, warehouse receipts.

### Billing & Milestones

**Payment milestones:** Contractual trigger points — e.g., "30% on shipping, 50% on delivery, 20% on completion." Portal tracks triggers based on actual logistics events.

**Milestone triggers:** Automatic based on events — PO Execution (date set), Shipping (shipment created), Customs Clearance, Delivery to Project. Depends on contract terms.

**Where to see milestone status:** Project Overview > Financial section > Milestone Summary Card (completion %, contract value, triggered amount, remaining) and Milestone Timeline.

**Cost per Watt:** Total module cost ÷ total wattage. $200K for 500kW = $0.40/W. Dashboard shows portfolio average.

**Projection costs:** Three categories — Freight (per leg based on distance/volume), Warehousing (entry/exit/storage fees), Milestones (contract triggers). Weekly Cost Projections table breaks it down.

### Account & Access

**Customer Admin permissions:** Create/manage projects, add/palletize module batches, create shipments, receive inventory, schedule deliveries, upload documents, view reports, manage projections, use Sunny. Can see all org data. Cannot add manufacturers/warehouses directly (can request them).

**Requesting manufacturers/warehouses:** Manufacturers > Request Manufacturers. For warehouses, contact Solterra account manager. Setup within 1–2 business days.

**Notification preferences:** Profile > Profile Settings. Toggle in-app and email notifications per event type. Default: in-app on, email off.

**Multiple org users:** Yes — contact account manager to add users with different roles/permissions.

**Changing password/profile:** Profile > Profile Settings to update name, email, phone, password.

### Troubleshooting

**Can't find project:** Check for active health filter (yellow banner) > Clear Filter. Try Table view or ask Sunny to search by name.

**No pallets to ship:** Ensure: batches added (Modules page), modules palletized (Module Overview > Generate Pallets), pallets not already shipped.

**Costs look wrong:** Mixed-wattage shipments distribute proportionally. Accessorial costs may be separate. Customer Cost ≠ Freight Cost. Contact account manager if still off.

**Quantity mismatch on receiving:** Record actual quantities, mark discrepancies, use damage reporting for expected vs actual vs damaged, upload photos.

**Can't find uploaded document:** Try Global Documents with project + type + date filters. Clear all filters and sort by most recent. May have been tagged differently.

**Can't add manufacturer/warehouse:** Customer Admins request, not add directly. Requires address verification and fee configuration by account manager.

**Sunny not responding:** Refresh page. Check internet connection and login status. Try new conversation via settings panel. Report bug if persists.

**Data looks wrong:** Screenshot it, contact account manager or use support form. Include: which page, what's wrong, what you expected.
